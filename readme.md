# Knapsack App

Приложение для наглядного сравнения алгоритмов решения 0/1‑задачи о рюкзаке.  
Графический интерфейс реализован на `customtkinter`, для визуализации производительности используются графики на базе `matplotlib`.

## Возможности

- **Генерация данных**:
  - случайное создание набора предметов с заданным количеством;
  - задание вместимости рюкзака.
- **Алгоритмы**:
  - Brute Force (полный перебор);
  - Dynamic Programming (динамическое программирование);
  - Branch and Bound (метод ветвей и границ);
  - Greedy (жадный алгоритм);
  - Genetic (генетический алгоритм).
- **Сравнение алгоритмов**:
  - таблица с максимальной ценностью и временем работы каждого алгоритма;
  - графики зависимости времени работы от:
    - числа предметов;
    - вместимости рюкзака.

## Требования

- Python 3.10+ (рекомендуется актуальная версия Python 3);
- Установленные зависимости из `requirements.txt`.

Список основных библиотек:
- `customtkinter` — современный UI для Tkinter;
- `matplotlib` — построение графиков;
- `numpy` — численные вычисления.
